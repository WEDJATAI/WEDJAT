# ZIM Integrated Shipping Services — Carrier Profile and Documentation

## Carrier overview

**ZIM Integrated Shipping Services Ltd.** is an Israeli container shipping company (founded 1945; Israel's national carrier). In **February 2026 the company was sold to Germany's Hapag-Lloyd for US$4.2 billion** — confirm current group integration status when booking. ZIM historically specialized in **niche/strategic trades** (Mediterranean, Black Sea, intra-Asia, Latin America, Oceania) and in reefer and dangerous-goods carriage, with a relatively young and LNG-powered fleet on mainline services.

## Documentation requirements

| Document | ZIM practice |
| --- | --- |
| Booking confirmation | Issued with booking number, vessel/voyage, cut-offs |
| Shipping instructions | Portal/EDI submission before the SI cut-off; draft B/L confirmation in-portal |
| Bill of lading | Original negotiable, sea waybill, telex release per SI election |
| VGM | Per SOLAS VI/2 before the VGM cut-off |
| Dangerous goods | IMDG data at booking; DGD required — ZIM has long specialized in DG carriage |
| Reefer data | Setpoints/monitoring instructions at booking |

ZIM publishes shipping-document guidance, country import/export guides, and free-time/demurrage-detention tariffs on zim.com — pair with the customs country guides in this corpus.

## Notes for shippers

- Under the 2026 Hapag-Lloyd acquisition, verify which services migrate to which group brands before relying on legacy portals.
- Strong niche-route coverage where mainline carriers have fewer direct calls.
