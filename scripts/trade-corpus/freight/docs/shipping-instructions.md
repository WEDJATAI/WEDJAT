# Shipping Instructions — SI Submission, Fields and Cut-off Times

**Shipping instructions (SI)** are the details a shipper provides to the carrier that the carrier uses to issue the bill of lading (or sea waybill) and to manifest the cargo to customs. Submitting complete, accurate SIs on time is one of the most operationally critical steps in ocean export: B/L data, customs filings and destination handling all derive from it.

## What the SI contains

| Group | Fields |
| --- | --- |
| Parties | Shipper, consignee, notify party (names, addresses) |
| References | Booking number, shipper's reference, PO numbers, forwarder reference |
| Routing | Port of loading, port of discharge, final place of delivery if multimodal |
| Cargo | Description (plain-language + HS code where required), marks & numbers, package count and kind, gross weight, volume |
| Equipment | Container numbers, seal numbers (when known at SI time) |
| Hazard | Dangerous-goods data (UN number, IMDG class, packing group, EmS) if applicable |
| Instructions | B/L type (negotiable / waybill / telex release), freight prepaid or collect, required issuance date, special instructions (temperature, reefer setpoint) |

## The cut-off chain

| Cut-off | Meaning |
| --- | --- |
| **SI cut-off (documentation cut-off)** | Last time B/L instructions can be submitted to the carrier for the sailing |
| **VGM cut-off** | Last time the verified gross mass (SOLAS VI/2) can be submitted — see the VGM reference |
| **CY / gate-in cut-off** | Last time the loaded container can enter the terminal yard |
| **Customs cut-off / VD documentation** | Last time export customs clearance can be lodged (jurisdiction-specific) |

Missing the SI cut-off forces either a B/L amendment fee, a booking rollover to the next vessel, or both.

## Process

1. After receiving the booking confirmation, the shipper prepares SIs from the commercial invoice and packing list (descriptions must match; see those references).
2. SIs are submitted through the carrier's portal (e.g. Maersk publishes a "How do I submit my shipping instructions" guide in its support FAQ), EDI (e.g. IFTMIN), or email for smaller lines.
3. The carrier's documentation team validates against the booking and issues a **draft B/L** for the shipper's confirmation.
4. The shipper checks the draft carefully (parties, cargo description, weights, Incoterm-based freight charges); amendments after issue are fee-bearing.
5. The final B/L is issued (originals printed, waybill, or telex-release/eB/L as instructed).

## Error prevention checklist

- Consignee/notify spelled exactly as the buyer requires (banks reject mismatches under UCP 600).
- Cargo description consistent across SI, invoice and packing list.
- Correct B/L type selected (order vs straight vs waybill vs telex).
- Number of originals specified (commonly three).
- HS code supplied where the destination requires it for manifest filing.
