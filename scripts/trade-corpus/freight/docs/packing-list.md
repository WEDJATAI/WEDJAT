# Packing List — Export Cargo Manifestation per Package

The **packing list** itemizes the contents of each package (box, pallet, crate, container) in an export shipment. It describes the physical composition of the goods: number of packages, weights, dimensions, type of packaging, and the detailed list of goods in each package. It accompanies the commercial invoice (which carries the financial data) and travels with the shipment for customs and warehouse handling.

## Contents

| Element | Notes |
| --- | --- |
| Reference data | Invoice number, buyer/PO reference, booking or B/L number |
| Shipper / consignee | Matching the invoice |
| Package index | Package number (1..N), type (carton/pallet/crate/drum) |
| Per-package detail | Marks & numbers, contents description, quantities, net/gross weight, dimensions |
| Totals | Total packages, total net/gross weight, total volume/cubic measurement |
| Country of origin | Where required |

## Who uses it and when

- **Customs** — verifies declared contents against physical inspection; supports the commercial invoice.
- **Carriers/forwarders** — cargo data for the booking, VGM computation, and dangerous-goods segregation.
- **Warehouse/packers at destination** — identifies and unpacks consignments.
- **Banks** — under documentary credits the packing list is a commonly required document (UCP 600).

## Practice notes

- Weights on the packing list feed the cargo declaration; for containers, the gross weights plus container tare feed the VGM calculation (see the VGM reference).
- Marks and numbers must physically appear on the packages and match the list and B/L exactly.
- For LCL/containerized cargo a container-level packing list (what is in each container, with seal numbers) is standard.
- The packing list is not a transport document nor a document of title — it cannot be negotiated.

## Relationship to other documents

| Document | Carries |
| --- | --- |
| Commercial invoice | Money: prices, terms, totals |
| Packing list | Matter: pieces, weights, packaging |
| Bill of lading | Title: receipt + contract + document of title |
