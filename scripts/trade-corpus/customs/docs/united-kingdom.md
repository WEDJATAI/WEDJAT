# United Kingdom — Import and Export Customs Documentation Guide

## Customs administration

**HM Revenue & Customs (HMRC)** administers customs; declarations run through the **Customs Declaration Service (CDS)** (which replaced CHIEF). Since **1 January 2021**, UK businesses importing from/ exporting to the EU require a **GB EORI number** on all customs declarations. Border Operating/ staged controls define checking practices.

## Import documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |

| Commercial invoice | All | Exporter | London Chamber import-entry checklist: EORI + CDS registration + commercial invoice and packing list |
| Packing list | All | Exporter | |
| Bill of lading / air waybill | All | Carrier | |
| **GVMS reference (GMR)** | RoRo movements | HMRC | Goods Vehicle Movement Service for port crossings |

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| Export declaration (CDS) | All exports | HMRC | |
| Commercial invoice + packing list | All | Exporter | |
| Export licenses | Controlled/ dual-use goods | DBT Export Control Joint Unit (ECJU) | See the Import-export licenses reference |
| Preference certificates/ origin statements | FTA claims | Chambers/ self-declarations | UK–EU TCA, UK–Turkey, CPTPP etc. |

## Import procedure overview

1. Obtain **EORI (GB)** + CDS access (a separate user ID per service per gov.uk guidance).
2. Pre-lodged or frontier declarations on CDS; GVMS GMR for accompanied RoRo.
3. Classification under the **UK Global Tariff** (HS-based 8/10-digit).
4. Duty + **import VAT 20%** (postponed VAT accounting available) paid/ deferred.
5. Release; records kept.

## Export procedure overview

1. Export declaration (CDS) by exporter/ agent.
2. Licences where controlled; origin statements for FTA destinations.
3. Carrier safety/ security (EXS) filing; departure confirmation.

## Duty and tax framework

- **UK Global Tariff** (since 2021): ad valorem on CIF by HS; UK–EU TCA zero-rates qualifying EU-origin goods.
- **Import VAT 20%** standard; postponed VAT accounting removes cash-flow burden.
- Excises on alcohol/ fuel/ tobacco.

## Special requirements and trade programs

- **CDS + EORI + GVMS** are the operational triad post-Brexit.
- Rules-of-origin compliance for EU trade (product-specific rules under the TCA).
- **AEO/CSEP- style** trusted trader schemes; customs warehousing/ inward processing support trading structures.
