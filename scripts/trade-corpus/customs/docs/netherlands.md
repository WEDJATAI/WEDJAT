# Netherlands — Import and Export Customs Documentation Guide (EU)

## Customs administration

The Netherlands is in the **EU Customs Union**: the **Union Customs Code (UCC)** applies; the **Dutch Customs Administration (Douane)** runs declarations through **Douane NL/ AGS-Douane** electronic systems, with the **Portbase** single window serving the port community (Rotterdam/ Schiphol). The **EORI number** is the trader's customs identity.

## Import procedure overview

1. **ENS pre-arrival** by the carrier (sea/ air).
2. Import declaration (AGS) with EORI; TARIC classification (CN 8-digit — see the HS reference).
3. Valuation (CIF transaction value; declaration > €20k), preference evidence.
4. **EU third-country duty + Dutch import VAT (21% standard)**; excises as applicable; Art. 23 licence (storage VAT deferral) widely used by traders.
5. Release; free circulation within the EU.

## Export procedure overview

1. Export declaration; risk-exit clearance at the EU border.
2. Dual-use licensing (RVO) where controlled.
3. Preference certificates for FTA destinations.
4. Customs supervision at exit; zero-rated VAT documentation.

## Duty and tax framework

- EU **common external tariff** on CIF; **import VAT 21%** (shifting to the destination-country VAT for B2C e-commerce consignments under IOSS); excises at clearance.
- **Article 23 VAT deferral** license (no cash VAT at import — accounted in returns) is the Dutch trading advantage; **bonded/customs warehousing** in Rotterdam's logistics parks.

## Special requirements and trade programs

- **EORI + KVK registration** as the trader stack (see the Netherlands entities guide).
- Portbase single-window messages for the port community.
- AEO certification; special procedures (inward processing, temporary admission).
