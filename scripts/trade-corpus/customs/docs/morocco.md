# Morocco — Import and Export Customs Documentation Guide

## Customs administration

**Administration des Douanes et Impôts Indirects (ADII, Moroccan Customs)** administers clearance; the **BADR** digital customs platform (with the **PortNet** single-window ecosystem) carries electronic declarations and agency validations. The customs declaration (***déclaration en douane**, historically **DUM** — déclaration unique de marchandises) is required for import and export through ports/ airports (trade.gov).

## Import documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| **Electronic customs declaration (DUM/ BADR)** | All imports | Customs broker via BADR | The broker submits the declaration and supporting documents in BADR |
| Commercial invoice | All | Exporter | |
| Bill of lading / air waybill | All | Carrier | |
| **Certificate of origin** | Imports | Chamber at origin | Per the standard set (Carraglobe: DUM with invoice, B/L, CO) |
| Packing list | All | Exporter | |
| **Import commitment/ domiciliation bancaire (IM)** | Commercial imports | Banks | FX domiciliation for payment control |
| Import licenses/ attestations | Restricted goods | Ministries/ ONSSA/ AMPP | Food/ health agencies |
| Conformity certificates | Regulated goods | ONSSA/ regulators | Post-clearup checks routed via BADR |
| Certificates for preferences | FTA claims | Origin authority | EU/ US/ GaFTA forms |

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| Export customs declaration (BADR/ DUM) | All exports | Broker | |
| Commercial invoice + packing list | All | Exporter | |
| Certificate of origin | Per destination | Chambers | EU association, US FTA, GaFTA forms |

## Import procedure overview

1. Bank domiciliation (IM) for the import; invoice/ contract registered.
2. Arrival; **broker files the DUM/ declaration in BADR** with invoice, B/L, CO.
3. Documentary or physical customs checks + **ONSSA/ regulator validations** where routed.
4. Classification (HS-based Moroccan tariff), valuation (CIF).
5. **Import duty (MFN/ preferential) + VAT 20% standard** + parafiscal taxes on imports; payment and release.

## Export procedure overview

1. Export declaration (BADR) via the broker.
2. Regulatory checks; certificate of origin (chamber) for preferences.
3. Loading; statistics; export proceeds domiciled.

## Duty and tax framework

- Import duties: MFN per HS; **FTA preferences** (EU association — industrial goods duty-free; US FTA on qualifying goods; GaFTA) with origin certificates.
- **VAT 20%** standard on imports (reduced/ exempt categories; suspension regimes for some production inputs); parafiscal import taxes apply to selected lists.

## Special requirements and trade programs

- **BADR/ PortNet** digital pipeline (IM domiciliation → DUM → agency validations).
- **ONSSA** food-safety and **AMPP** product-safety interfaces at clearance.
- **Tanger Med/ free zones**: export-platform regimes with customs advantages (see the Morocco entities guide).
- Moroccan documentation typically French-language; notarized/ consular legalization where required.
