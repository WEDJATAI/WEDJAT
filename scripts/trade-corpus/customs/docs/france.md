# France — Import and Export Customs Documentation Guide (EU)

## Customs administration

France is in the **EU Customs Union**: the **Union Customs Code** framework is applied by the **Direction Générale des Douanes et Droits Indirects (DGDDI, French Customs)** — the douane.gouv.fr portal (DEB/ DELTA systems) handles electronic declarations. **EORI** identifies traders; the SAD is the standard written declaration model.

## Import documentation requirements (extra-EU imports)

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| **SAD (Single Administrative Document)** | All imports | Customs (DELTA system) | The official model for written declarations — describes goods and their movement, encompasses duties and VAT |
| **EORI number** | All declarants | Customs | Trader identification |
| Commercial invoice | All | Exporter | |
| Packing list | All | Exporter | |
| Bill of lading / air waybill | All | Carrier | |
| Entry Summary Declaration (ENS) | Pre-arrival | Carrier | EU risk-based filing |
| Customs Value Declaration | Value > EUR 20,000 | Importer | EU rule |
| Certificates of origin/ preference proofs | Preferential claims | Origin authority | EUR.1, REX |
| Import licenses | Controlled goods | SISSE/ EU | Dual-use (see the Import-export licenses reference) |
| Document retention | All | Trader | **Import documentation must be retained at least 3 years from the customs declaration** (customs; longer for VAT) |

## Export documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| Export declaration (DELTA) | All extra-EU exports | Customs | |
| **DEB/ DES** | Intra-EU trade | Customs | Exchange-of-goods statistical declaration |
| Commercial invoice + packing list | All | Exporter | |
| Export licenses | Dual-use | SISSE (duaux usages) | |
| Certificates of origin | Per destination | Chambers (CCI) | EUR.1/ FTA forms |
| Common transit/ EU transit documents | Transit movements | douane.gouv.fr | Logistics envelope/ accompanying documents (per the portal's doc list) |

## Import procedure overview

1. ENS pre-arrival; arrival.
2. SAD/ DELTA declaration with EORI; TARIC/ CN classification (see the HS reference).
3. Valuation; preference evidence; checks.
4. **EU third-country duty + French import VAT (20% standard)**; excises as applicable.
5. Release; records retained 3+ years.

## Export procedure overview

1. Export declaration (DELTA); customs exit validation.
2. DEB/ DES statistics for EU flows.
3. Dual-use licensing where controlled; CCI certificates of origin for FTA destinations.
4. Exit; VAT zero-rating documentation.

## Duty and tax framework

- EU **common external tariff** on CIF; **import VAT 20%** (2.1%/ 5.5%/ 10% reduced bands); excises on alcohol/ tobacco/ energy.
- Special procedures: warehousing, inward processing, **AEO** certification.

## Special requirements and trade programs

- **EORI** + SIRET integration (see the France entities guide).
- douane.gouv.fr publishes paperless-declaration guidance (DELTA) and document-scan rules.
- French port/ airport community systems (SOPRANO-adjacent messaging) connect customs to terminals.
