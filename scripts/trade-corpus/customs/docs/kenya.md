# Kenya — Import and Export Customs Documentation Guide

## Customs administration

Kenya's customs function sits under the **Kenya Revenue Authority (KRA Customs Services)**; the **iCMS** (Integrated Customs Management System, replacing SIMBA) enables submission of all customs documents into a single-window system, and the **Kenya TradeNet** single window (run by SIFAX/KenTrade) aggregates import permits and agency approvals. Kenya is in the **EAC Customs Union** (common external tariff on HS-based codes).

## Import documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| **Import Declaration Form (IDF)** | All imports | appointed banks/ TradeNet → KRA | Required for all imports; contains a summary of supporting documents (invoice etc.) |
| Customs entry/ declaration (iCMS) | All | KRA | Electronic |
| Commercial invoice | All | Exporter | |
| Packing list | All | Exporter | |
| Bill of lading / air waybill | All | Carrier | |
| **Certificate of conformity (PVoC)** | Designated goods | KEBS-appointed agencies | Pre-export verification of conformity |
| Import licenses/ permits | Regulated goods | Regulators (KEBS, Pharmacy, KEPHIS…) | Via TradeNet |
| PIN (KRA) | All importers | KRA | Trader identity (see the Kenya entities guide) |
| **IDF-related levies (RDL/ IDF fee)** | All | Banks/ KRA | Paid at IDF stage |

## Export documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| Export declaration/ entry | All exports | KRA (iCMS) | |
| Commercial invoice + packing list | All | Exporter | |
| Certificate of origin | Per destination | Chamber/ KEBS/ ministry | EAC/ COMESA certificates |

## Import procedure overview

1. Importer (KRA PIN) applies for the **IDF** (through appointed banks, integrated with TradeNet); pays IDF/ RDL levies.
2. Pre-export conformity (PVoC certificate) for designated goods.
3. On arrival: **entry lodged on iCMS**; risk-based documentary/ physical checks; permits validated.
4. Classification (EAC tariff on HS), valuation (CIF).
5. **Duties + VAT 16% + levies (IDF 2.5%, RDL 2%** on qualifying goods — verify current rates) paid; release.

## Export procedure overview

1. Export declaration on iCMS; permits/ certificates as applicable.
2. Origin certification (COMESA/ EAC forms) for preference claims.
3. Loading; export statistics; export-processing-zone/ EPZ regimes support export manufacturing.

## Duty and tax framework

- **EAC common external tariff**: 0/ 10/ 25% bands by HS (sensitive items 35%+).
- **VAT 16%** on imports (with exemptions list); **IDF** and railway-development levies on imports.
- EPZ/ SEZ regimes with duty/VAT relief for export-oriented structures.

## Special requirements and trade programs

- **Kenya TradeNet single window** — permits + IDF pipeline.
- **PVoC conformity** for consumer goods (see the Inspection certificates reference).
- **EAC Customs Union** origin (EAC certificates); **COMESA** preferences; AGOA eligibility for US-bound apparel.
- **iCMS** replaced SIMBA (historical references to SIMBA remain in guides).
