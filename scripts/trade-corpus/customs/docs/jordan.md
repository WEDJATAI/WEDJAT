# Jordan — Import and Export Customs Documentation Guide

## Customs administration

**Jordan Customs (Department of Customs, شرطة/ دائرة الجمارك)** administers clearance under the Customs Law; declarations run through the ASYCUDA-based electronic system. **Only an authorized forwarding agent in Jordan can process the customs declaration**, which must be filed with the supporting documents (trade.gov Jordan guide). The Jordan trade repository (traderepository.customs.gov.jo) publishes per-tariff document requirements.

## Import documentation requirements

| Document | Required for | Issuing/checking authority | Notes |
| --- | --- | --- | --- |
| **Customs declaration** | All imports | Authorized Jordanian forwarding agent | Agent-filed requirement |
| Commercial invoice | All | Exporter | Legal name/ tax data must match the declaration and supporting documents |
| Packing list | All | Exporter | |
| Bill of lading / air waybill | All | Carrier | |
| Certificate of origin | Imports (preference/ trade-remedy) | Chamber at origin | GaFTA/ US-Jordan FTA claims |
| Import licenses/ clearances | Restricted goods | Sector ministries (FDA, JFDA etc.) | Product-specific |
| **Conformity/ type certificates** | Regulated devices/ goods | Regulators + customs | Imported devices must be accompanied by the required certificates and the customs transaction (Jordan customs trade repository) |
| Insurance certificate | CIF-based valuation | Insurer | |

Importer must be a registered Jordanian entity (commercial registration + tax number — see the Jordan entities guide).

| Export declaration | All exports | Customs (via agent) | |
| Commercial invoice + packing list | All | Exporter | |

## Import procedure overview

1. Importer (registered entity) engages a licensed **forwarding agent** to file the declaration with the document set.
2. Classification (HS-based national tariff), valuation (CIF basis).
3. Regulatory validations (JISM standards, JFDA food/drug, ministry permits) as routed.
4. **Customs duty + 16% sales tax (VAT)** + fees; preferential rates with valid certificates.
5. Release; post-clearance audit rights.

## Export procedure overview

1. Export declaration via agent; commercial docs.
2. Certificate of origin (chambers; US-Jordan FTA/ GaFTA forms).
3. Loading; statistics; export proceeds tracked through banks.

## Duty and tax framework

- MFN tariff per HS; **general sales tax 16%** on imports (with reduced/exempt schedules).
- Preferential regimes: **US-Jordan FTA** (qualifying rules of origin), **GaFTA**, EU association — certificates required at entry.

## Special requirements and trade programs

- **Authorized-agent filing** — importers cannot self-lodge.
- **Aqaba Special Economic Zone (ASEZ)** — separate customs regime (see the Jordan entities guide).
- Jordan customs publishes the trade repository per HS code — use it to pre-verify documents.
