# Italy — Import and Export Customs Documentation Guide (EU)

## Customs administration

Italy is in the **EU Customs Union**: the **Union Customs Code (UCC)** framework applies, administered by the **Agenzia delle Dogane e dei Monopoli (Customs Agency)** through the **AEDI/ customs clearance systems**. The **EORI number is mandatory for any economic operator lodging customs declarations within the EU** (country code + unique registration number). Intra-EU trade is VAT-only (no customs declarations).

## Import procedure overview

1. ENS pre-arrival filing; arrival at Italian port/ airport.
2. Import declaration (SAD-based electronic) with EORI; classification in TARIC/ CN 8-digit (see the HS reference).
3. Valuation; preference/ origin evidence; documentary/ physical checks.
4. **EU third-country duty + Italian import VAT (22% standard)**; excises (e.g. alcohol, tobacco) at clearance.
5. Release; free EU circulation.

## Export procedure overview

1. Export declaration; customs exit validation.
2. Dual-use licensing where controlled (UAMA).
3. Preference certificates for FTA destinations; Intrastat for EU flows.
4. Exit confirmation; VAT zero-rating documentation.

## Duty and tax framework

- EU **common external tariff** on CIF; **import VAT 22%** with input-VAT deduction; excises per product.
- Special procedures: customs warehousing, inward processing, **AEO** benefits.

## Special requirements and trade programs

- **EORI** via the Agenzia (integrated with fiscal registration — see the Italy entities guide).
- Italian port community systems (e.g. community networks at Genoa/ Milan terminals) interface with customs.
- Anti-fumigation/ SPS checks at border inspection posts for food/ plants.
