# HS Chapter 80 — Tin; articles thereof

Harmonized System **chapter 80** (Section XV) of the universal 6-digit tariff nomenclature. This chapter contains 4 four-digit headings and 5 six-digit subheadings.

Codes are universal up to 6 digits (WCO Harmonized System); countries extend them to 8–10 digits in national tariff schedules (e.g., US HTS, EU TARIC, Egyptian tariff).

## Headings and subheadings

| HS code | Level | Description |
| --- | --- | --- |
| 8001 | Heading | Tin; unwrought |
| 800110 | Subheading | Tin; unwrought, not alloyed |
| 800120 | Subheading | Tin; unwrought, alloys |
| 8002 | Heading | Tin; waste and scrap |
| 800200 | Subheading | Tin; waste and scrap |
| 8003 | Heading | Tin; bars, rods, profiles and wire |
| 800300 | Subheading | Tin; bars, rods, profiles and wire |
